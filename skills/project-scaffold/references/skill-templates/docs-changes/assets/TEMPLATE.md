# 变更目录模板

## 1. `INDEX.md` 索引

目标结构：一张“文件 | 说明”表，每个 change 一行。

```markdown
| 文件                                         | 说明                                |
| -------------------------------------------- | ----------------------------------- |
| [NNNN-{kebab-case}.md](NNNN-{kebab-case}.md) | CHANGE-NNNN：{一句话描述}（{状态}） |
```

## 2. `NNNN-{kebab-case}.md` change 单篇

目标结构：四位递增编号、中文标题、状态与影响层元信息，以及四段正文。

```markdown
# CHANGE-NNNN — {中文名}

- 状态：{规划中 / 执行中 / 已实行}
- 影响层：{L1 / L2 / L3 / L4 / common，可多选}
- 关联：{涉及的既有文档}

## §1 现状（as-is）

{当前应用、模块、接口、数据结构和文档入口，并给出 File:Line 或文档引用。}

## §2 改动方案（to-be）

{变更点、涉及文件、接口与数据结构、迁移和兼容方案。}

## §3 验收

{用例、机检和文档同步清单。}

## §4 沉淀与归档

{变更内容并入的层文档、归档方式和本 change 的删除条件。}
```
