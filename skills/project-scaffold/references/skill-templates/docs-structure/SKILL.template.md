# docs-structure — 目录结构与文档 ↔ 代码映射

## 定位与管辖文档

本 skill 管辖贯穿层目录结构文档 `docs/common/STRUCTURE.md`，维护全项目文件组织以及文档与代码的对应关系。common 文档在 L1 至 L4 文档之后综合生成；修改任何文档前先读本 skill 维护的映射，再定位对应代码。

跨文档编排、目录漂移处理和文档初始化归 `docs-align` skill。生成或重建目标文档前，先读 [assets/TEMPLATE.md](assets/TEMPLATE.md)，按其中章节编号与标题层级写目标文档。

## 读取

- 编辑、新增或重建目标文档前，先读本 skill、[assets/TEMPLATE.md](assets/TEMPLATE.md) 和已有的 `docs/common/STRUCTURE.md`。
- 直接扫描项目实际目录树，不抽样；同时读取项目宪法、应用架构文档、对外接口文档和业务功能清单。
- 应用架构文档由 `docs-application-architecture` skill 维护，对外接口文档由 `docs-inbound` skill 维护，业务功能清单由 `docs-business` skill 维护；本 skill 读取并使用这些产物，不复制其内容。
- 读取代码核对目录与文档映射，发现漂移时以代码和实际目录为事实来源。
- 目录树使用 ASCII 代码块，文档与注释使用中文；正文只写当前态，不写历史因果。

## 生成流程

1. 先读 [assets/TEMPLATE.md](assets/TEMPLATE.md)，再扫描项目完整目录、代码模块、应用划分、接口位置和业务功能位置。
2. 按模板逐节填写真实目录、职责、约束、组织原则和当前漂移，不套用固定层数或命名风格。
3. 已有目标文档时提取仍有效的项目事实，按模板重建目录树与职责映射，删除过期目录和幽灵目录。
4. 目录与职责定义发生漂移，或需要新增、调整目录时，询问用户确认处理方式。
5. 生成后检查目录映射的完整性、当前态一致性与关联文档状态。

## 更新流程

- 编辑、新增、重建目标文档，或应用划分、接口契约、功能清单变化导致目录增删时进入更新流程。
- 先读目标文档与 [assets/TEMPLATE.md](assets/TEMPLATE.md)，再扫描实际目录和受影响文档；只更新发生变化的内容，保留仍有效的当前态信息。
- 新增或调整目录前与用户确认；目录职责定义与代码不一致时，以代码和实际目录为依据修正文档。
- 章节删除或迁移后同步重编号并清理旧引用，避免文档树出现幽灵目录。
- 更新完成后复核文档与代码映射，并把需要跨文档处理的事项交给 `docs-align` skill。

## 联动

- `docs-application-architecture` 的应用划分或模块归属变化，联动目录树和目录职责。
- `docs-inbound` 的接口位置或契约组织变化，联动接口相关目录映射。
- `docs-business` 的功能清单或待规划能力变化，联动实现目录与文档目录的对应关系。
- 根项目宪法、项目实际目录和其他文档发生变化时，联动本 skill 的当前态记录。
- 跨文档扫描、漂移分诊、目录同步和旧文档迁移由 `docs-align` skill 编排；本 skill 不承担全仓编排。

## 完成判定

以下全部通过才算完成：

- 目标文档按模板组织，标题与章节编号和层级一致，模板未定义的 frontmatter 或其他元信息不补写。
- 目录树与项目实际目录一致，无缺失目录、幽灵目录或未说明的新增目录。
- 目录职责表与目录树逐项对应，每个目录都写明用途与约束。
- 文档与代码映射可定位到实际文件和模块，业务待规划能力未被提前落成实现目录。
- 漂移记录只写当前状态和当前处理结论，不写历史因果、迁移占位或已删除内容。
- 正文不写模板指引、构建元信息、占位符、填充说明或治理套话；同一信息只维护一处，跨层引用按项目宪法方向组织。
- 关联的应用架构、接口、业务文档和项目宪法已完成一致性检查。
- 正文无 `SSOT`、单一事实源或唯一事实源字样，无加粗与 emoji，目录树保持 ASCII 文本。

## 边界

- 只维护 `docs/common/STRUCTURE.md`，不改业务代码、接口实现、测试文件或其他文档正文。
- 不规定固定目录层数、目录名称或技术框架模板；一切以项目实际分层和代码事实为准。
- 不复制其他文档的业务内容，不写历史与决策原因；跨文档对齐、迁移和初始化由 `docs-align` skill 负责。
- 发现目录与代码冲突时只修正文档映射并报告，不静默改动代码；不自动 commit 或 push。
