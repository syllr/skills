# deploy-ops — L3 部署域

本 skill 是 L3 部署域唯一入口：一进来先看「分诊」，再按类进入对应流程。部署知识的 SSOT 是各环境 `DEPLOYMENT.md`
，执行时现场读目标环境文档照做，本
skill 不复制任何命令与环境信息。

- 每个发布环境一个目录 `docs/deployment/<env>/`，内含说明书 `DEPLOYMENT.md` 与配置 `.env.<env>`；说明书按应用为中心组织（§3.1
  应用清单，每个应用一章含其部署与配置密钥与资产与运行产物；末尾是全量部署与种子凭据）。
- 环境名 = 目录名 = `.env.<env>` 后缀，一律相同；只装发布环境，开发流程（本机 standalone）不是发布环境、不进此目录，其说明与纪律归项目本机
  rule。
- 不设跨环境共享配置目录：键集以各环境 `.env.<env>` 彼此一致为准；脚本不进 `docs/deployment/`，登记在各环境 `DEPLOYMENT.md`
  各应用章的「资产」节。
- 运行产物（日志 / 备份 / 模型权重缓存 / 临时产物）归各应用章的「运行产物」节；业务数据模型归 `docs/L2/DATA-MODEL.md`，两者不重复。
