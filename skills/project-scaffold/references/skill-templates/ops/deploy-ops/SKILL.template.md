# deploy-ops — L3 部署域

本 skill 是 L3 部署域唯一入口：一进来先看「分诊」，再按类进入对应流程。部署知识的 SSOT 是各环境 `DEPLOYMENT.md`
，执行时现场读目标环境文档照做，本 skill 不复制任何命令与环境信息。

只装发布环境：开发流程（本机 standalone）不是发布环境、不进部署资产目录，其说明与纪律归项目本机 rule。
