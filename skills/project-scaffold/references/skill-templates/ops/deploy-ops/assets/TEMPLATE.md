# DEPLOYMENT — 部署与发布

## 1. 部署概述

写明部署形态、环境用途、运行形态、状态、依赖关系、不部署项与待澄清项。

### 1.1 部署形态与环境

写环境总览表，列为：环境、用途、运行形态、状态；补充环境一致性、依赖关系、不部署清单和待澄清项。

### 1.2 术语表

写部署环境、运行形态、产物、编排组、版本标识等术语及其含义。

## 2. 环境

写各环境的用途、入口、配置来源、依赖与运行形态，以及环境之间的拓扑关系。

### 2.1 环境矩阵

写环境矩阵表，列为：环境、用途、入口、配置来源、依赖、运行形态。

### 2.2 环境拓扑

写按环境分区的 D2 部署容器图，展示用户、各环境应用、数据与外部依赖。

## 3. 部署单元与依赖服务

写应用对应的部署单元、依赖服务、运行形态、健康检查与回滚方式。

### 3.1 部署单元

写部署单元表，列为：单元、类型、standalone 运行形态、dev 运行形态、健康检查、回滚。

### 3.2 依赖服务

写依赖服务表，列为：依赖服务、类型、部署方式、被谁依赖、健康检查、回滚。

## 4. standalone（开发者本地）开发启动

写 standalone 环境的前置条件、启动步骤、验证方式与必要的种子凭据信息。

### 4.1 后端启动

写后端启动命令、配置来源、依赖参数与启动结果。

### 4.2 前端启动

写前端安装、启动命令、API 地址与访问入口。

### 4.3 验证

写后端健康检查、关键接口或页面验证、命令与预期结果。

### 4.4 种子凭据（如有）

写种子用户的凭据、角色与用途。

## 5. dev 发布部署

写 dev 环境的发布形态、版本标识、发布步骤、运维命令、参数与回滚方式。

### 5.1 形态总览

写应用组件、镜像或运行环境、产物、端口与依赖服务的对应关系。

### 5.2 发布前置规则（版本标识）

写发布前的版本检查、版本标识来源、容器或产物中的版本信息。

### 5.3 发布流程

写发布脚本、发布命令、执行步骤、数据库迁移、验证与回滚入口。

### 5.4 运维命令

写启动、查看状态与日志、查看版本、停止服务等运维命令及用途。

### 5.5 参数与配置文件

写后端配置、compose 变量、端口、覆盖来源、回滚方式与待补充项。

## 6. 密钥与配置管理

写密钥配置的分层、来源与注入方式。

### 6.1 应用层密钥

写应用层密钥表，列为：密钥项、环境变量或来源、用途。

### 6.2 中间件层密钥

写中间件层密钥表，列为：密钥项、环境变量或来源、用途。

## 7. 部署配置文件详解

按 `docs/deployment/` 目录树写部署资产，写明路径、归属、生效机制与用途。

### 7.1 `configs/`

写配置模板目录及其环境、归属和生效机制。

#### 7.1.1 `.env.example`

写后端基础变量模板的路径、归属、用途与生效机制。

#### 7.1.2 `compose.env.example`

写 compose 层变量模板的路径、归属、用途与生效机制。

### 7.2 `standalone/`

写 standalone 环境配置的路径、归属、内容范围与生效机制。

### 7.3 `dev/`

写 dev 环境配置目录及其下各类配置资产的路径、归属、内容范围与生效机制。

#### 7.3.1 `docker-compose.dev.yml`

写应用编排文件的服务、构成、依赖关系与生效机制。

#### 7.3.2 `.env.dev`

写 dev 后端容器配置的变量范围、归属、注入方式与生效机制。

#### 7.3.3 依赖编排

写依赖服务的编排文件、配置、端口、重建入口与生效机制。

### 7.4 发布与重建脚本

写发布、重建、回滚等脚本的路径、用途、执行位置与关联章节。

### 7.5 运行类资产

写与代码或运行环境耦合的资产路径、用途、归属与保留位置。

### 7.6 版本发布记录（按需）

写版本号规则、发布日期、变更内容、环境与版本状态。
