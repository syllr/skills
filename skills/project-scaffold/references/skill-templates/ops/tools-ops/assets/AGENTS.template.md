## 调用约定

<!-- 生成提示:begin -->
写各工具通用的调用约定（各自的细节在 `tools/<类>/AGENTS.md`）：① 选环境——按该工具的「环境参数」表选中该环境那一行，把该行连接参数拼进命令（连接信息不落配置文件）；②
多步骤 / 多子工具——用该工具自己的序列参数编排（如 webmcp 的 `--seq '<JSON 数组>'`，同一会话内按数组顺序执行、跨步保态、可从前面结果插值）；③
输出与退出码——stdout 只输出一行 JSON，退出码 0 成功 / 1 断言失败 / 2 参数 / 3 网络 / 4 数据层 / 10 配置；④
参数一律不给默认值，缺任一必填项即报错。
