### 子工具（工具归属页面）

<!-- 生成提示:begin -->
本工具触达的是 **前端页面**（整体：本前端应用的全部页面，而非某一个页面）。子工具不是本工具内置，而是各页面代码在组件挂载时注册、
卸载时注销；本表只登记 **本前端的页面清单**（路径 + 页面名 + 该页前端代码文件），子工具在运行时用 `--list --path <页>`
实时取，文档不抄——不漂移。

子工具的入参怎么读、怎么调，在本节统一说明一次，不逐页重复。
<!-- 生成提示:end -->

| 页面 | 页面名 | 页面组件文件 |
|------|--------|--------------|

- 取子工具：`--list --path <页>` 返回该页当前真实注册的子工具（name / description / inputSchema / annotations）。
- 怎么读入参：读返回的 `inputSchema`——`properties` 键名 / 类型、`required`、`enum`，即调用入参。
- 怎么调：`{"name":"{子工具}","args":{…}}` 交给 `{序列参数}`；跨页先 `{"goto":"{path}"}`。
- 页面代码位置 / 启用门控：{如 `frontend/**/webmcp/`、`VITE_WEBMCP=1`}。
