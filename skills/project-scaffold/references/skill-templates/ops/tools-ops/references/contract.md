# 统一契约（每个工具都要满足）

- 输出：stdout 只输出一行 JSON；人类诊断走 stderr。
- 退出码： **从 0 起连续、无跳号**（0 = 成功）；各类具体的码在 `call-*.md` 列全，无自造码。
- 工具不做断言：工具只返回数据，断言由 AI 依据返回数据判断。
- 参数：一律不给默认值——任一必填参数缺失即 fail-fast（参数类退出码），不得用默认值静默兜底。
- 连接信息：走命令行参数（每个工具用 flag 接收 host / port / user / pass / … 等），不读任何配置文件。
- 校验：发请求前做 fail-fast 契约校验（输入键不在被测契约声明内即报错并列出可用键）。
- 写操作须先得到用户授权；AI 不得未经授权执行写。
- 数据 / 中间件直连型工具默认只读，写加 `--write` 才允许（唯一带写开关的类）；接口型（inbound / outbound）与页面调用型（webmcp）没有写开关。
- `--help` 可用。
- 具体实现由项目自行落地。
