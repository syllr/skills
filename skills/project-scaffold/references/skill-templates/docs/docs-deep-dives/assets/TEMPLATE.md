# docs-deep-dives 文档模板

## 产物一：{name}.md

本节写：单个系统级问题深潜文档的标题、层归属、内容范围与文件头。

### 文档头

本节写：声明单篇标题、L2 层归属与系统级问题范围。

~~~yaml
---
title: <name> — 系统级问题深潜
layer: L2
~~~

### 文件头

本节写：声明本文档回答一个系统级问题，层归属为 L2，内容可跨越 L1-L4。

# <name> — 系统级问题深潜

> <系统级问题的一句话描述>。

## 1. 总览（应用级时序图）

本节写：用一张 Mermaid sequenceDiagram 展示应用与系统之间的端到端交互。

~~~mermaid
sequenceDiagram
  participant A as <应用或系统 A>
  participant B as <应用或系统 B>
  A->>B: <接口或事件>
  B-->>A: <响应或结果>
~~~

## 2. 应用内部流程

本节写（按需）：用 Mermaid sequenceDiagram 展示应用内部领域实体与领域服务的协作。

~~~mermaid
sequenceDiagram
  participant E as <领域实体>
  participant S as <领域服务>
  E->>S: <领域动作>
  S-->>E: <处理结果>
~~~
