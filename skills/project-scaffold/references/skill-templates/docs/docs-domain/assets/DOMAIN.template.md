## 1. {聚合根}

<!-- 生成提示:begin -->
一个聚合根一章，按本域实际的聚合数量顺延编号（1..n，n 为聚合个数），其后各固定章节接着往下编，章节标题写聚合根名。
章内依次写：根的属性表、各实体的属性表（每张表前用一行粗体标出对象名与「聚合根 /
实体」）、聚合类图、不变量、领域操作、状态机、领域事件；只有根、没有实体的单对象聚合不画聚合类图。

- 表列：属性 / 类型 / 说明。
  本域是能力域（没有聚合与状态机）时，本章标题写「域内索引」：列只读实体（实体 / 类型 / 说明）并给每个实体一节业务属性，规则照
  `### 不变量` 写，聚合类图、领域操作、状态机、领域事件四节只保留标题；章首点明三件事——实体形态（只读实体与生命周期说明）、写侧
  action 与状态机归属（对应域文档）、接口表方法性质（接口契约签名说明）。
  本章没有内容时只保留标题，不写内容。
