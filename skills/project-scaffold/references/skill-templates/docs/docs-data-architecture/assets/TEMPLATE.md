# L2 数据架构文档

## 1. 数据架构愿景与原则

说明业务数据的物理来源，以及日志、锁、缓存、临时产物、编号序列等技术数据，并说明与领域模型、代码和存储选型理由的关系。

## 2. 数据资产分类

使用分类表区分业务数据与技术数据，并呈现数据项、数据资产、存储位置和归属模块，以 Mermaid flowchart 呈现数据全景。

## 3. 存储选型与拓扑

使用表格呈现存储类型、技术、承载数据和备注，选型理由引用技术架构。

## 4. 数据流转与血缘

呈现业务数据从同步、采集、生成到归档的主链，以及从主链分叉或回流的支链。

### 4.1 主链

使用 D2 血缘图呈现必经的正向数据流转。

### 4.2 支链下钻

呈现主链之外的分叉与回流数据链。

#### 4.2.1 支链名称

使用 D2 小图呈现该支链的数据流转，并说明其未放入主链的原因。

## 5. 物理存储格式

按物理存储或数据源呈现存储内容、键模式，并按初始化、业务写入、同步和清理分步说明数据构建方式。

使用 D2 表关系总览呈现表间关联且不展开字段，使用单表清单列出表名、说明与字段来源，并说明数据构建方式。
