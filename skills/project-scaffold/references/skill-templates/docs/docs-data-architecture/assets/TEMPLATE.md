图的形态（脱敏示例，节点标签按项目实际替换）：

```d2
# 图名: 数据血缘主链
# 视角: 数据流转视角（正向必经链路）
# 用途: 表达业务数据从产生到归档的必经流转
# 反映的问题: 数据按什么顺序流转、每个环节产出什么、责任落在哪

vars: {
  d2-config: {
    layout-engine: elk
  }
}

主链: {
  grid-rows: 1
  grid-columns: 1
  grid-gap: 16
```

#### 3.2.1 支链名称

<!-- 生成提示:begin -->
D2 小图呈现该支链的数据流转，并写明它未放入主链的原因。图的形态（脱敏示例）：

```d2
# 图名: 支链 — <支链名称>
# 视角: 数据流转视角（支链）
# 用途: 表达该支链从主链分叉或回流到主链的路径
# 反映的问题: 它从主链哪个环节分叉、走向哪里、为什么不能放进主链
# 边界: 只画该支链，不重复主链已表达的环节

vars: {
  d2-config: {
    layout-engine: elk
  }
}

支链: {
  grid-columns: 1
  grid-gap: 12
  style.font-color: "#1e293b"
  style.border-radius: 16

  n1: { label: "<环节一>\n（<说明>）"; width: 620; height: 52; class: module }
  n2: { label: "<环节二>\n（<说明>）"; width: 620; height: 52; class: module }
}

支链.n1 -> 支链.n2: <同步流转> { style.stroke: "#2563eb" }
```
