# test-asset 模板资产使用说明

本目录（用例卡模板）的全部内容本质都是模板——生成/编写测试用例卡时参考这里的结构与契约来写，不是拿来即用的成品、也不是唯一实现。参考 = 看结构、照契约、按被测系统实况写。

## 资产清单

| 资产           | 是什么          | 怎么用                                                                                                       |
| -------------- | --------------- | ------------------------------------------------------------------------------------------------------------ |
| `api-case.md`  | API 用例卡模板  | 生成 API 卡：复制结构（头 + Case N 五段）→ 替换接口/实体/Case 内容 → 落到 `docs/test/test-cases/api/<实体>/` |
| `flow-case.md` | FLOW 用例卡模板 | 生成 FLOW 卡：复制结构 → 按 USER-STORY 场景填充 → 落 `flow/<场景>/`                                          |

## 测试工具集已独立为 test-tools skill

测试工具集（架构规范、参考实现、生成/维护/执行）不再由本目录承载——已独立为 test-tools skill（`.opencode/skills/test-tools/`）。需要生成/维护测试工具，或直接调用工具查数据/对账时，走 test-tools skill；本目录只保留用例卡模板。

> 测试工具集的唯一职责：测试用例的所有操作与 AI 直接查数据都必须经它执行（不写 curl、不裸 SQL）。工具架构与新增 vs 修改决策见 test-tools skill 的 `references/test-tools.md`，参考实现见其 `assets/reference-impl/`。
