# 用例卡模板资产

本目录是**用例卡模板**：编写/生成测试用例卡时参考这里的结构与契约来写，不是拿来即用的成品。参考 = 看结构、照契约、按被测系统实况写。规范见 [../references/case-writing.md](../references/case-writing.md)。

| 资产           | 是什么          | 怎么用                                                                                                       |
| -------------- | --------------- | ------------------------------------------------------------------------------------------------------------ |
| `api-case.md`  | API 用例卡模板  | 生成 API 卡：复制结构（头 + Case N 五段）→ 替换接口/实体/Case 内容 → 落到 `docs/test/test-cases/api/<实体>/` |
| `flow-case.md` | FLOW 用例卡模板 | 生成 FLOW 卡：复制结构 → 按 USER-STORY 场景填充 → 落 `docs/test/test-cases/flow/<场景>/`                     |

> 用例的创建/更新/删除/执行一律经 test-ops skill（唯一入口）；新增正式卡经 DoD 草稿晋升，见 SKILL。
