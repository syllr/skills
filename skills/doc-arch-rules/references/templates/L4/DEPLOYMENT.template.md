## 6. 密钥与配置管理

> 【指引】配置分层：代码内置默认值（兜底）→ 环境级配置（域名/开关）→ 运行期配置（热更新）→ 密钥（严禁入库/落日志/落前端包，用密钥管理服务注入，支持轮换）。密钥安全红线详见 SECURITY §6。

| 层             | 内容            | 管理方式                        |
| -------------- | --------------- | ------------------------------- |
| 代码内置默认值 | 兜底配置        | 代码库（git 可追踪）            |
| 环境级配置     | 域名、URL、开关 | 环境变量/配置文件（按环境分离） |
| 运行期配置     | 动态开关、阈值  | 配置中心（可热更新）            |
| 密钥           | 密钥/token/证书 | 密钥管理服务 + 注入（严禁入库） |
