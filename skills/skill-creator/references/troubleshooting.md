# 故障排查指南（示例）

> 本文件是 `references/troubleshooting.md` 的标准示例——教你在 skill 里放一份"故障排查"参考文档。

## 定位

- 收集 skill 使用中最常见的报错、现象与解决办法
- SKILL.md 引用方式：`[故障排查指南](references/troubleshooting.md)`

## 内容结构

```markdown
## 常见问题

### <问题现象>

- **报错信息**：
- **原因**：
- **解决**：

### <问题现象 2>

- ...
```

## 编写要点

- 每条：现象 → 原因 → 解决，三段式
- 报错信息用代码块原样贴出（便于搜索匹配）
- 排序：按出现频率从高到低
