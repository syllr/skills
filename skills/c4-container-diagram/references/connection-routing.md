## 6.3 层间箭头：父级到父级（完整路径，否则静默重复节点）

**箭头只连接层容器（父级）之间**，不连接层内子容器——这是本 skill 的层间箭头铁律（用户明确要求）：

```d2
# ✅ 对：父级到父级（推荐，层间箭头）
整体架构.入口层 -> 整体架构.业务能力层: "HTTP 调用" { style.stroke: "#2563eb" }

# ❌ 错：子级到子级（连接层内子容器，非层间箭头）
整体架构.入口层.h1 -> 整体架构.业务能力层.api: "调用"
```

**必须写完整路径**（`整体架构.入口层` 而非 `入口层`），否则 d2 会**静默创建顶层同名节点**（validate 不报错，渲染才暴露）：

```d2
# ❌ 错：会创建顶层 `入口层` 重复节点
入口层 -> 业务能力层: "调用"

# ✅ 对：完整路径
整体架构.入口层 -> 整体架构.业务能力层: "调用"
```

## 6.12 双向箭头

上下层之间需要表达"请求/响应"双向时用 `<->`（无向边），单向用 `->`。**路径同样用完整路径，且只连层容器父级之间、不连层内子容器**（见 §6.3）：

```d2
# ✅ 对：完整路径 + 父级到父级
整体架构.层A <-> 整体架构.层B: "HTTP"

# ❌ 错：简化路径（会静默创建顶层重复节点）
层A <-> 层B: "HTTP"
```
